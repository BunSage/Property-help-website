# Property Help website — ready-to-upload files

This folder contains the website files directly at the top level:

```text
PropertyHelpWebsite/
  index.html
  styles.css
  gallery.css
  script.js
  gallery-data.json
  images/
  .nojekyll
  PropertyHelpWebsite.code-workspace
  README.md
```

`styles.css` is the main stylesheet; it does not need to be named `style.css`. The HTML already points to the correct files. Keep the filenames and the images folder together.

## Open and edit on your PC

Double-click `PropertyHelpWebsite.code-workspace` to open this folder in VS Code. Select `index.html` in the sidebar to edit the page. Open `index.html` in your web browser to preview; save your edits and refresh the browser to see changes.

## Upload preparation

If using the ZIP, extract it first. Upload the contents of this folder to the root of your website repository, with `index.html` directly at the root. Do not upload only the ZIP or place the site inside an extra `dist` folder.

This is a static website; no build command or package installation is needed. `.nojekyll` marks the files for static hosting.

These files have been prepared locally. This package has not been uploaded to GitHub and does not connect a Google Business Profile. The existing hosted Sites version is separate, and edits here do not automatically update it.

## Contact behavior

The quote form prepares a text message to (772) 306-3020 in the visitor's messaging app. The visitor reviews and sends it. The website does not store requests or send them automatically. Copying the prepared request is available as a fallback.

"Property Help" is the temporary business name currently used in the site.
